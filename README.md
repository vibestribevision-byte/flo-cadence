# Flo Cadence — Official Site

Minimal, dark & moody artist landing page for **Flo Cadence**.

Live site: https://vibestribevision-byte.github.io/flo-cadence/

## Structure

- `index.html` — the entire site (single-file: markup, styles, and a tiny script)
- `assets/` — space for images, audio, and other media

## Editing

Everything lives in `index.html`. To make it yours:

- **Social links** — update the URLs in the `<nav class="socials">` block
- **Contact email** — replace `bookings@flocadence.com`
- **Tagline / copy** — edit the `.tagline` paragraph
- **Colors** — tweak the CSS custom properties in `:root`

## Deploy

Any push to `main` publishes automatically via GitHub Pages.
